# MessageBird Testprojekt

Dieses Projekt dient als Testimplementierung einer SMS-Versand-Anwendung über die MessageBird API.

**Datenbank**

Für die Speicherung der Anwendungsdaten wurde MongoDB verwendet. Die Datenbank wird online gehostet, sodass keine lokale Datenbank bzw. Datenbankdatei mit dem Projekt mitgeliefert werden muss.

**MessageBird**

Bei der Registrierung bei MessageBird wurde bewusst darauf verzichtet, eine Telefonnummer zu hinterlegen. Dadurch stehen aktuell keine Wallet-Credits für den tatsächlichen SMS-Versand zur Verfügung.

Der entsprechende SMS-Versand ist daher in diesem Projekt nur theoretisch implementiert und konnte nicht mit einer tatsächlich versendeten SMS getestet werden.
